# Love-App

A mobile application built with Flutter and Dart.

## 🚀 Features

- Cross-platform mobile app (Android & iOS)
- Organized architecture with models, services, and reusable widgets
- Clean and modular codebase

## 📁 Project Structure

├── models/ # Data models
├── screens/ # App screens/pages
├── services/ # Business logic & API/data services
├── utils/ # Helper functions and utilities
├── widgets/ # Reusable UI components
└── main.dart # App entry point


## 🛠️ Tech Stack

- **Flutter**
- **Dart**

## 📖 Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/harryvaishnani/Love-App.git
   cd Love-App
```
2. Get dependencies:
```bash
   flutter pub get
```
3. Run the app:
```bash
   flutter run
```
